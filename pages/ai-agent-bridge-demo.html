5 bước, không cần người can thiệp

Poller hỏi baocao mỗi 30 giây. Thấy task ở AI Queue thì claim ngay bằng cách đổi status - vòng poll sau không thấy nữa nên không xử lý trùng.

KANBAN AI Queue Task gán cho account của Bridge
->poll 30s
POLLER Đang làm Claim task, phân tích + comment lên baocao
->phân tích xong
CLAUDE CLI Coding Code, chạy test, retry tối đa 3 lần
->test pass
GIT + GITLAB Push Commit, push nhánh ai/task-code, tạo MR
->MR sẵn sàng
KANBAN Review Comment kết quả + báo qua Telegram
Vì sao polling, không webhook: baocao chưa hỗ trợ webhook. Claim bằng cách đổi status làm luôn nhiệm vụ chống xử lý trùng, không cần cơ chế riêng.

Chuẩn bị sẵn cho Q & A

Chi phí vận hành thế nào?
Dùng chung Claude Code CLI subscription, không phải API pay-per-token. Chi phí chủ yếu là thời gian chờ - chạy async, không tốn giờ developer.
Nhiều task cùng lúc thì sao?
Mỗi repo có 1 _GIT_LOCK riêng nên task cùng project chạy tuần tự. Task khác project (khác repo) chạy song song bình thường.
Secret có bị lộ không?
File .env* tự động bị unstage trước khi commit - không bao giờ lọt vào MR hay lên GitLab.
Nếu Claude hiểu sai task?
Test fail thì retry tối đa 3 lần. Nếu vẫn sai, con người review MR và tự sửa hoặc đóng MR - không ảnh hưởng code trên main.
Muốn thử ngay: kéo một task rõ ràng vào cột AI Queue trong tuần này.
