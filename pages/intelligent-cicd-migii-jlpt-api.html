Bốn tầng của hệ thống

✓
Auto Testing
Unit Tests + E2E Tests tự động trên CI

Unit Tests

  • Chạy trên mọi MR và branch main/develop
  • Container node:20-alpine trên remote server — môi trường sạch, nhất quán
  • Coverage report Cobertura + lcov — tích hợp Jenkins recordCoverage
  • Sau build: tự tạo task trên Baocao với link coverage
  • Test fail không block pipeline — E2E vẫn chạy tiếp

E2E Tests

  • Spin MySQL + Redis thật qua docker-compose — không mock DB
  • Test container kết nối vào cùng compose network
  • Timeout 20 phút, cleanup hoàn toàn sau mỗi build
  • Fail → UNSTABLE, không block deploy develop
  • Fail trên production → block deploy (FAILURE)
Chạy trên: MR, main, develop, release/*, testing/*
⟳
RAG — Codebase Context Engine
Semantic search toàn bộ codebase — luôn fresh sau mỗi deploy

Index 3 collections

  • docs: CLAUDE.md, PRD, TEST_PLAN, feature specs, API/DB docs
  • tests: Tất cả *.spec.ts và *.e2e-spec.ts
  • source: Toàn bộ TypeScript source (trừ spec + d.ts)
  • Embedding model: all-MiniLM-L6-v2, ChromaDB persist trên disk
  • Incremental — chỉ re-embed file thực sự thay đổi (~30s)

Tự động reindex trên CI

  • Chạy sau mỗi deploy develop và production
  • Self-heal: nếu image migii-rag mất → tự build lại từ Dockerfile
  • Hai index song song: api_test (develop) và api (production)
  • Dev dùng: make index, make search q="...", make gen q="..."
  • Fail → UNSTABLE, không block deploy
Reindex sau: Deploy develop · Deploy production
⚡
MCP Server — RAG trong IDE
Claude Code truy cập codebase context ngay trong session làm việc

Cách hoạt động

  • rag/mcp_server.py expose tool rag_search qua stdio
  • Claude Code spawn server 1 lần khi mở session — luôn có sẵn
  • Embedding load lazy lần đầu — các lần sau gần như tức thì
  • Log rotate 1MB vào rag/rag_server.log
  • Config sẵn trong .mcp.json — không cần setup thêm

Dev nhận được gì

  • Skills tự gọi rag_search ngầm: /vibe-feature, /test:unit-test, /solo:coding
  • Context từ cùng session — có toàn bộ conversation history
  • Debug retrieval: make search q="..." in JSON để xem context trước
  • Brainstorm standalone: make gen q="..." mở session Claude riêng
Config: .mcp.json · Tool: rag_search · Server: mcp_server.py
◈
AI Code Review
Claude phân tích diff + RAG context, post comment tự động lên MR

Quy trình 3 bước

  • ① Lấy diff: chỉ file .ts source (bỏ spec + d.ts), truncate 40k chars
  • ② Query RAG: trích tên file từ diff → tìm pattern tương tự trong codebase (top-3)
  • ③ Gọi Claude API: claude-sonnet-4-6, max 1024 tokens, system prompt chuyên biệt
  • Post comment qua addGitLabMRComment — không cần token riêng
  • Fail → UNSTABLE, không block merge

Claude được hướng dẫn kiểm tra

  • Layer violations: logic trong controller/entity, raw SQL trong service
  • SQL injection: nối string thay vì parameterized query
  • Auth missing: endpoint nhạy cảm thiếu middleware
  • Premium check sai: phải dùng sumRemainingTime > 0
  • Business rules: max 3 devices, header format Authorization: <token>
Output: Critical · Warnings · Suggestions
