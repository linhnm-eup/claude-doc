🤖 1. Orchestrator.md

Why you need an orchestrator:

Problem: Claude Code doesn't auto-trigger, doesn't run parallel, doesn't schedule

Solution: Orchestrator layer between you and agent

Layers:

You → Orchestrator (decides when/how) → Agent → Task

Types of orchestrators:

Type Tools When to use
Visual/Low-code n8n, Make Non-programmers, visual design
Agent Framework LangGraph, CrewAI Developers, complex logic
Specialized Cline Kanban Coding tasks, kanban board

Giai đoạn deploy:

  1. Phase 1: Cline Kanban + Claude Code (manual trigger)
  2. Phase 2: + Composio AO (auto-fix CI)
  3. Phase 3: + n8n (webhook triggers from Jira/GitHub)

4. Multi-Agent Collaboration (Team simulation)

  • AutoGen, CrewAI (dual role)
  • Mạnh: Simulate real team
  • Yếu: Dễ "nói chuyện phiếm", tốn token

Decision table:

Situation Use Why

🤖 3. Cline & Kanban.md

Cline = VS Code extension cho AI coding

Features:

  • Chat with AI inside VS Code
  • File browser
  • Terminal execution
  • MCP server support
  • Optional: Kanban board for task tracking

Cline Kanban (new board UI):

  • Browser-based kanban
  • Run multi-agent tasks parallel
  • Dependency management
  • Supports: Cline, Claude Code, Codex

Comparison:

OpenHands Cline Kanban Claude Code
Model 1 agent isolated Many agents parallel 1 agent CLI
Sandbox Docker ✅ No No
Orchestration Built-in hidden Visual board Manual
Cost Free Free $100/month

Best for: Team dev with many parallel tasks

🤖 4. n8n Workflow.md

Workflow automation tool (open source)

What it does:

  • Visual node-based workflow builder
  • Connect 400+ apps (Slack, Sheets, GitHub, Jira, etc.)
  • Automation: "When X happens, do Y then Z"
  • Self-hosted or cloud

Example workflow:

New user signup 
  ↓ (webhook trigger)
Save to database
  ↓
Send welcome email (SendGrid)
  ↓
Add to CRM (HubSpot)
  ↓
Schedule follow-up in 3 days
  ↓
Notify #sales on Slack

n8n vs OpenClaw:

n8n OpenClaw
Design Node-based (kéo thả) Agent-based (prompt)
Stability Rất cao (predictable) Trung bình (LLM creative)
Connections 400+ APIs Browser automation
Best for Repetitive, stable flows Research, variable tasks

Combine them: n8n (skeleton) + OpenClaw (brain)

🤖 5. OpenHands.md

Autonomous software engineering agent

What makes it special:

  • Event-sourced architecture (replayable)
  • Docker sandbox (safe, isolated)
  • Multi-LLM routing (choose model per task)
  • Built-in security analysis
  • 64k GitHub stars (proof of capability)

vs LangGraph:

OpenHands LangGraph
Type Agent product Framework (DIY)
Use "I need AI to code" "I need to build AI system"
Setup Docker run, ready Write code, setup, deploy
Flexibility Lower (fixed features) Higher (full control)
Best for Quick autonomy Custom architecture

Not competing: OpenHands = finished car, LangGraph = car factory

🤖 6. LangGraph.md

Framework to build custom agent workflows

Core idea: State machine for agents

┌─────────────────┐
│ STATE (memory)  │
│ task, code,     │
│ tests, feedback │
└────────┬────────┘
         ↓
┌─────────────────┐
│ NODE: Planner   │ ← Agent breaks down task
└────────┬────────┘
         ↓
┌─────────────────┐
│ NODE: Developer │ ← Agent writes code
└────────┬────────┘
         ↓
┌─────────────────┐
│ NODE: Tester    │ ← Agent tests code
└────────┬────────┘
         ↓
    [pass/fail?]
     /         \
   YES         NO
    ↓           ↓
   END      [feedback loop]

vs n8n:

  • n8n: "Skeleton" (fixed structure)
  • LangGraph: "Bricks" (build anything)

Best for:

  • Complex business logic
  • Multi-step reasoning
  • Self-correcting workflows
  • Production systems

Learning curve: Medium (need Python)

🤖 7. OpenClaw.md

AI agent for automation (browser control)

  • Controls mouse, keyboard, browser
  • Can scrape web without API
  • More "human-like" automation
  • Good for: "Can't find API? Use browser"

vs n8n:

  • n8n: API-based (stable)
  • OpenClaw: Browser automation (flexible)

✨ Key Insights (Compressed)

  1. Layered approach: Agent ≠ Orchestrator. Agent does work, orchestrator decides when/how.

  2. Right tool for task:

    • Simple coding → Cline
    • Automation → n8n
    • Complex logic → LangGraph
    • Autonomous → OpenHands

  3. Free is possible:

    • Cline (free)
    • n8n (free self-host)
    • Gemini API (free tier)
    • Claude (free, limited)

    Total cost: $0-50/month for solo dev

  4. Learning path: Chatbot → Single agent → Workflow → Multi-agent → Production

  5. Daily workflow: Use 3-4 different tools per day based on task type

  6. Cost optimization:

    • Local models when possible
    • Batch API calls
    • Free tier aggregation
    • Avoid token waste
